Datenfluss im Detail

  1. Offline erfassen: Jede Taube wird weiterhin in localStorage gespeichert.
  2. Online erkannt: navigator.onLine + erfolgreicher Ping zum Worker.
  3. Sync auslösen: Tablet sendet den verschlüsselten Backup-JSON an /sync.
  4. Worker speichert: Entschlüsselung nicht nötig — S3 speichert den Blob AES-verschlüsselt.
  5. Zuschauer/Rangliste abrufen: GET /data liefert den aktuellen Blob zurück.
  6. Client entschlüsselt: Passwort wird clientseitig zu Schlüssel abgeleitet.

Schlüssel-Entscheidung: Verschlüsselung

A

Client-seitige Verschlüsselung

Passwort → PBKDF2 → AES-GCM. Worker sieht nur verschlüsselten Blob. S3 ist öffentlich unlesbar.

B

Server-seitige Verschlüsselung

Worker verschlüsselt mit einem Geheimnis aus Workers Secrets. Einfacher für Clients, aber Worker kennt Klartext.
